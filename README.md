# 🌿 Personal Portfolio Website

A modern, interactive, and responsive portfolio website built to showcase technical skills, projects, and development capabilities.

The website features an elegant visual design, smooth animations, interactive elements, and user-friendly navigation.

## 📌 Project Overview

This project was developed to create a professional digital portfolio with a focus on clean UI, simple navigation, and an engaging user experience.

It demonstrates the use of frontend technologies to build a complete, self-contained website.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Created the structure and different sections of the website. |
| CSS3 | Designed layouts, colors, typography, animations, and responsive styling. |
| JavaScript | Added interactivity, navigation behavior, event handling, and dynamic UI interactions. |
| Google Fonts | Enhanced typography and visual presentation. |
| Base64 Image Embedding | Embedded the profile image directly into the HTML file. |

## 🎨 Design & Development Approach

### 1. UI/UX Design
- Created a premium dark-themed interface.
- Used a combination of chocolate brown, forest green, olive, and warm ivory colors.
- Focused on clean layouts, visual hierarchy, and readability.
- Designed a consistent look across different website sections.

### 2. Website Structure

The portfolio includes:

- **Hero Section:** Main introduction and visual presentation.
- **About Section:** Overview section.
- **Skills Section:** Technical skills and tools.
- **Projects Section:** Showcase of selected projects.
- **Contact Section:** Contact and social connectivity options.

### 3. Interactive Features
- Interactive navigation.
- Smooth scrolling and section transitions.
- CSS animations and visual effects.
- JavaScript-powered interactions.
- Resume button interaction.
- Responsive layout for different screen sizes.

## 📂 Project Structure

```text
portfolio/
│
├── index.html       # Main portfolio website
└── README.md        # Project documentation
```

The website is self-contained. HTML, CSS, JavaScript, and the embedded image are included in the main HTML file.

## ⚙️ How to Run Locally

No additional installation or build tools are required.

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.

The portfolio website will run locally.

## 🚀 Deployment

The website can be hosted using **GitHub Pages**, allowing the static website to be published directly from a GitHub repository.
